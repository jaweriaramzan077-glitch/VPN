# VPN
# VPN (Virtual Private Network)

## 1. What is a VPN?

VPN stands for **Virtual Private Network**.
It creates a secure and encrypted connection between a device and a VPN server over the Internet.

---

## 2. How VPN Works

A VPN creates an encrypted **tunnel** between the user and VPN server.

```text
Device → Encrypted Tunnel → VPN Server → Internet
```

---

## 3. Uses of VPN

* Secures Internet traffic
* Protects data on public Wi-Fi
* Provides secure remote access
* Helps protect privacy
* Can hide the user's public IP address from websites

---

## 4. VPN Encryption

Encryption converts readable data into a protected form so unauthorized users cannot easily understand it.

---

## 5. VPN Tunnel

A VPN tunnel is a protected connection through which VPN traffic travels.

```text
User ===== Secure VPN Tunnel ===== VPN Server
```

---

## 6. Types of VPN

### Remote Access VPN

Allows a user to securely connect to a private network from a remote location.

### Site-to-Site VPN

Connects two or more private networks securely over the Internet.

---

## 7. VPN Protocols

Common VPN protocols include:

* WireGuard
* OpenVPN
* IPsec
* IKEv2

---

## 8. VPN vs Firewall

| VPN                           | Firewall                    |
| ----------------------------- | --------------------------- |
| Creates secure connection     | Controls network traffic    |
| Encrypts VPN traffic          | Allows or blocks traffic    |
| Used for secure remote access | Used for network protection |

---

## 9. Advantages

* Secure communication
* Data encryption
* Secure remote access
* Protection on untrusted networks
* Can change the apparent public IP address

---

## 10. Limitations

* Does not provide complete anonymity
* VPN speed may vary
* Does not protect against every cyber attack
* VPN provider must be trusted

---

## 11. Important Terms

| Term       | Meaning                     |
| ---------- | --------------------------- |
| VPN        | Virtual Private Network     |
| Tunnel     | Protected connection        |
| Encryption | Protects data               |
| VPN Server | Handles VPN connections     |
| Protocol   | Rules for VPN communication |

---

## 12. Short Viva

**VPN:** Virtual Private Network.

**Main purpose:** To create a secure connection over an untrusted network.

**VPN Tunnel:** A protected connection between a device and VPN server.

**Two VPN protocols:** WireGuard and OpenVPN.

**Site-to-Site VPN:** Securely connects separate networks.
